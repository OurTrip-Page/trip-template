# Sources

Raw originals live here: booking emails, PDF confirmations, screenshots, pasted
text. Files are named by the SHA-256 of their contents, so archiving the same
email twice is a no-op.

**Nothing in this directory is ever published.** The publish step only derives
artifacts from `trips/<slug>/index.html`; it does not look at, copy, or serve
anything under `sources/`, regardless of privacy markers.

Why keep them at all: extraction is fallible. When a confirmation is parsed
wrongly — or cannot be parsed at all — the original is still here, linked from a
dated note in the trip's private inbox. Nothing you send us gets thrown away
because we failed to understand it.
